## 專案背景

Tomoroll 需要一個能清楚說明公司定位、同時方便團隊長期維護的官方網站。我們選擇以內容為核心，避免第一版加入不必要的後台與動態服務，把資源集中在資訊架構、閱讀體驗與效能。

## 我們如何進行

- 以簡潔的頁面架構整理公司、服務、團隊與專案資訊。
- 建立一致的視覺系統，讓「向明日推進」成為網站的主要動態意象。
- 使用 Astro、TypeScript 與 Tailwind CSS 製作靜態網站。
- 以 Markdown 管理團隊與專案內容，保留審核及版本紀錄。
- 透過 Cloudflare Workers Static Assets 提供 Preview、全球 CDN 與自動部署。

## 成果

網站在不依賴資料庫的前提下，具備響應式版面、內容驗證、基本 SEO 與無障礙考量。這也是一套能隨公司內容逐步擴充的基礎，而不是一次性的展示頁。
